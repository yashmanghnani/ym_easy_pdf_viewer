## 2.0.0

- Require Flutter 3.50.1 and Dart 3.14.
- Migrate to standalone Material UI; apps using Material types must migrate too.
- Update Android build tooling and package dependencies.
- Bridge the legacy number picker during the Material migration.


## 1.0.0

- Modernized the package for Flutter 3.47.2 and Dart 3.13.2.
- Updated Android builds to AGP 9.1, Gradle 9.3.1, Java 17, and the Flutter Plugin DSL.
- Updated iOS deployment support to iOS 15.
- Fixed page streaming, page bounds validation, asset filename collisions, and document page caching.
- Reduced viewer rebuilds and fixed controller/document lifecycle handling.
- Improved Android bitmap/resource cleanup and iOS PDF/cache resource management.
- Added typed document errors, linting, tests, and refreshed documentation.
